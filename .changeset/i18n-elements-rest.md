These elements' interface text follows the interface locale a player publishes, else the item's `language`, in fourteen languages, and an element stamps `lang` and `dir` only when the item declares a language. Text that rendered in English whatever the language now translates: match-list's screen-reader names, drag instructions and drag announcements, multi-trait-rubric's table headers, score labels, half-point note and print notice, fraction-model's configuration labels and warning dialog, and graphing-solution-set's warning dialogs. number-line's point-limit message uses the singular for a single point. math-templated's alternates note shows in the interface locale unless the item carries an authored note; a stored copy of the default note counts as no note.
