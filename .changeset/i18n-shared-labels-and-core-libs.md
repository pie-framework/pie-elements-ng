The show and hide toggles for teacher instructions and rationale carry their own translated labels, so every element that shows them names them the same way in each supported language. Passage labels its region and tabs in all fourteen supported languages. The editor toolbar and the math answer fields name themselves in the item language from their own catalogs; a language that is not yet loaded shows English briefly and switches once it arrives.
