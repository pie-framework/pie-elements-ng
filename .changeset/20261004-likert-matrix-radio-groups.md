A likert scale and each matrix row are one radio group, named by the likert prompt or the row label, so screen readers announce the question or row on entering its options. Each group is a single tab stop: Tab moves on to the next row, and the arrow keys move the selection within the group, recording the response on each press. Students who tabbed to an option and pressed Space now use the arrow keys instead.
