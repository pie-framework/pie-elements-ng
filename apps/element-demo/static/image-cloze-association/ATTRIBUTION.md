# Image cloze association demo fixtures

All files in this directory are original repository fixtures with no third-party content. They redraw the images the image-cloze-association demo loaded from `app.fluence.net`, so the demo apps and their specs load no outside host.

- `tire-pieces-graph.svg`: the 465×313 graph. The dashed boxes sit where the model's `response_containers` place the drop zones.
- `with-tire-recycling.svg`, `without-tire-recycling.svg`: the two 145×55 data labels.
