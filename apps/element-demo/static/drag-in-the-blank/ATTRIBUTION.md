# Drag in the blank demo fixtures

All files in this directory are original repository fixtures with no third-party content. They redraw the arrays the drag-in-the-blank demo loaded from `app.fluence.net`, so the demo apps and their specs load no outside host.

- `array-3x8.svg`: 3 rows of 8, the pencils problem.
- `array-36-div-9.svg`: 4 rows of 9, the jelly beans problem.
- `array-5x7.svg`: 7 rows of 5, the water bottles problem.

Each array matches its choice's alt text and the scoring key. The originals had the first two swapped: the "3x8 array" image showed 36 dots and the "36÷9 array" image showed 24.
