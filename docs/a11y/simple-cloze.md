# Simple Cloze A11y Coverage

## Intended Use

Students type a short response into a cloze input embedded in prompt context.

## Automated Coverage

- `simple-cloze-input-label`: programmatic input label, keyboard entry path, and input assistance.
- `simple-cloze-evaluate-feedback`: evaluate-mode feedback, clear error/correctness text, and status semantics.

## Not Covered / Manual

- Confirm the input label includes enough surrounding context.
- Confirm feedback is associated with the input and understandable when read out of visual order.
