# Venn Classification A11y Coverage

## Intended Use

Students classify tiles into Venn diagram regions, including overlap regions and optional author-provided region label overrides.

## Automated Coverage

- `venn-tile-region-keyboard`: tile names, region names, keyboard placement, target size, and diagram alternatives.
- `venn-region-overrides`: author-provided region labels, tile labels, keyboard reachability, and graphic alternatives.

## Not Covered / Manual

- Confirm the full tile placement workflow can be completed without drag gestures.
- Confirm screen readers announce picked-up tile, available regions, and dropped region clearly.
