# Placement Ordering A11y Coverage

## Intended Use

Students arrange choices into an ordered sequence, typically through placement or drag/reorder interactions.

## Automated Coverage

- `ordering-keyboard-reorder`: ordered choices, guide labels, reorder/drop interactions, keyboard reachability, and target size.
- `ordering-evaluate-feedback`: evaluate-mode order feedback and status-message semantics.

## Not Covered / Manual

- Confirm the full reorder workflow works without drag gestures.
- Confirm screen readers announce item position, movement, and final order.
