# Match List A11y Coverage

## Intended Use

Students create associations between prompts and answer choices, often displayed in two columns.

## Automated Coverage

- `match-list-association-controls`: association prompts, answer labels, and keyboard reachability.
- `match-list-evaluate-feedback`: evaluate-mode association feedback and status-message semantics.

## Not Covered / Manual

- Confirm prompt/answer relationships are preserved without visual column layout.
- Confirm answer movement or reassignment has a clear keyboard and screen-reader workflow.
