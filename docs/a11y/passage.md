# Passage A11y Coverage

## Intended Use

Students read passage content, including prose and poetry, as context for other assessment interactions.

## Automated Coverage

- `passage-reading-structure`: headings, body text, navigation structure, and reading order.
- `passage-poetry-reading-order`: poetry line/stanza structure, headings, and source order.

## Not Covered / Manual

- Confirm hidden layout text does not create confusing screen-reader output.
- Confirm line breaks, stanza grouping, and passage titles are announced appropriately.
