# @pie-lib/math-input-mathlive

## 2.0.1

### Patch Changes

- [#629](https://github.com/pie-framework/pie-elements-ng/pull/629) [`b93d1e1`](https://github.com/pie-framework/pie-elements-ng/commit/b93d1e1d4d775938abc5d51df0529d6f7fd88aa3) Thanks [@chillenious](https://github.com/chillenious)! - The show and hide toggles for teacher instructions and rationale carry their own translated labels, so every element that shows them names them the same way in each supported language. Passage labels its region and tabs in all fourteen supported languages. The editor toolbar and the math answer fields name themselves in the item language from their own catalogs; a language that is not yet loaded shows English briefly and switches once it arrives.

- [#704](https://github.com/pie-framework/pie-elements-ng/pull/704) [`fabbfd6`](https://github.com/pie-framework/pie-elements-ng/commit/fabbfd6760a323315d4cb0dacef8cafc4d62fdbb) Thanks [@lakatosandrei](https://github.com/lakatosandrei)! - Keep the first keypad key pressed in a math field. A re-render right after the key landed wrote the field's starting value back over it, so in the editor's math toolbar the first tap after "Insert math" was often lost (PIE-1509).

- [#610](https://github.com/pie-framework/pie-elements-ng/pull/610) [`bcb1514`](https://github.com/pie-framework/pie-elements-ng/commit/bcb15145be9740e5ed5f355a37c9bc0f2d9540e9) Thanks [@PatriciaRomaniuc](https://github.com/PatriciaRomaniuc)! - Keep a steady, visible cursor in the math entry area, and in a math answer block, while a keypad button has keyboard focus, and remove it when focus moves anywhere else. Tab and Shift+Tab in the math entry area now move focus on straight away and leave the cursor where it was, instead of first moving it through the expression to its end; Tab still accepts a suggestion while a latex command is typed.

- [#664](https://github.com/pie-framework/pie-elements-ng/pull/664) [`ca1d678`](https://github.com/pie-framework/pie-elements-ng/commit/ca1d678afbf8e3291f2611de49611cc13276625b) Thanks [@PatriciaRomaniuc](https://github.com/PatriciaRomaniuc)! - Accept typed input while a math keypad button has keyboard focus: letters, digits and symbols go into the math entry area, or the math answer block, at the cursor, as if typed there, and Backspace and Delete delete there; focus stays on the button. Space, Enter, Tab, the arrow keys and Ctrl, Cmd and Alt shortcuts keep their keypad roles.

- [#664](https://github.com/pie-framework/pie-elements-ng/pull/664) [`f2c076c`](https://github.com/pie-framework/pie-elements-ng/commit/f2c076c334457490e07ea3995639998f178140af) Thanks [@PatriciaRomaniuc](https://github.com/PatriciaRomaniuc)! - Turn off MathLive's autocomplete for a latex command typed after `\`, in the math entry area and in answer blocks: no suggestion popover, and no completion shown inline. With a math keypad button focused, a latex command typed after `\` now goes to the field, and Space, Enter or Escape finishes it there instead of pressing the button. Option characters on macOS (π, ≠) typed with a keypad button focused are now sent to the field. In the math toolbar, typing with the "+ Response Area" button focused, or with a keypad button reached through it, now goes to the editor, as it does from the keypad.

- [#671](https://github.com/pie-framework/pie-elements-ng/pull/671) [`63067bb`](https://github.com/pie-framework/pie-elements-ng/commit/63067bbba582453a7c93207838bb0ad4b530f32f) Thanks [@CarlaCostea](https://github.com/CarlaCostea)! - Answers typed in the MathLive editor score again as they did in MathQuill (PIE-1514). MathLive writes a single-digit argument without braces (`\frac12`, `2\frac34`, `\sqrt2`), which the math scorer does not parse, so a correct fraction or root scored 0, and an author's key typed with the fraction key matched nothing else. The editor now stores the braced form MathQuill stored (`\frac{1}{2}`). In Advanced Multi, the complete answer is the expression with the answers in place, as MathQuill gave it (`x=2`), no longer wrapped in `\MathQuillMathField[r1]{2}`, which no key matched.
